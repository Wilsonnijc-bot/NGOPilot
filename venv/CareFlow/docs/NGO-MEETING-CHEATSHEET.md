# NGO 面談 Cheatsheet · 護流 CareFlow

> 30 分鐘實地交流用。建議列印 A4 一張隨身、或攤在 iPad 上。
> 對應信件三大用例：**①批量表單** / **②圖片→表格** / **③整理紀錄稿**。

## 三、Demo 流程（10 分鐘黃金路徑）

> 全程在 demo NGO 帳號跑，**任何上傳檔案都不外傳**。建議順序由「最具視覺衝擊」到「最易理解」：

1. **θ Upload（90 秒）** — 上傳一份貴中心常用的 PDF 空白表（可請對方現場給）
   - 講解：AI 識別欄位 → 社工審查 → **存為永久模板**
   - 賣點：「**用過一次就再用唔需要設定**」
2. **α Volunteer Upload（120 秒）** — 拖入 3-5 張手填表照片
   - 講解：AI 抽取 → 列表審查 → 匯出 Excel
   - 賣點：「**100 張紙人手要 1 日，呢度 5 分鐘搞掂**」
3. **γ Welfare Form（120 秒）** — 拖入一張 HKID 照片 + 選表單（CSSA / 長者咭）
   - 講解：OCR 抽資料 → 自動填 PDF → 社工核對打勾
   - 賣點：「**填表錯字、漏項唔再會發生**」
4. **β Home Visit（120 秒）** — 用一段預錄家訪語音
   - 講解：粵語轉文字 → 結構化 → 報告 .docx
   - 賣點：「**社工放錄音就走，返去報告已經草擬好**」
5. **歷史 + 模板（60 秒）** — 點 `/history` 帶過
   - 賣點：「**所有案卷可批量合併匯出做月報、季報**」

> 中途若同工發問，**讓他們親手拖個檔案上去**，比你示範強 10 倍。

## 六、聆聽清單（你問 NGO 嘅問題）

工具 demo 完之後，**轉成聽嘢模式**，問：

1. 「**現時邊個流程同工最頭痕？最佔時間？**」
2. 「**填得最多嘅政府表係邊幾張？**」（記低 → 接落去做 γ 預設模板）
3. 「**家訪紀錄而家用咩格式？係 Word template 定 paper form？**」
4. 「**有冇試過用 ChatGPT / 其他 AI 工具？點解最後冇繼續用？**」
5. 「**機構 IT 政策對於 cloud AI 有冇規定？**」（決定 deployment 模式）
6. 「**如果試行三個月免費，你哋希望我哋優先做邊樣？**」

> 每個答案記係 notebook、現場唔好評論、回去再消化。

## 十一、Q&A 示例（普通话 · 现场可直接念）

> 以下问答按"NGO最常问"频率排序。括号里是补充话术，可视对方反应增减。

### A. 数据隐私与安全

**Q1：你们的工具会把长者的个人资料上传到自己的服务器吗？**
A：不会。我们的设计是"**数据留在贵中心，模型走出去**"——AI 调用只发送当下需要处理的那一段文字或图片，处理完立即丢弃。我们的服务器**不存档案、不存对话记录**。如果贵中心 IT 政策更严格，我们也可以做**完全本地部署**，用开源模型替换云端 API，全程离线。

**Q2：万一 AI 把长者的 HKID 当成日志记录下来怎么办？**
A：我们在 v0.4.5 版本专门做了一次安全审计，已经把 LLM 原文片段从日志里去掉，**只记录长度而不记录内容**。录音转写稿用 Fernet 对称加密保存，可以设定到期自动焚毁。如果需要，我们可以提供审计报告。

**Q3：你们用的 DeepSeek 和 GPT 是中国/美国的，资料会不会经过境外？**
A：DeepSeek 服务器在亚洲（主要中国大陆），GPT 我们走的是**微软 Azure 香港/东亚节点**——不是 OpenAI 直连。整条数据链都在亚洲。如果机构政策要求**完全境内**，我们可以切换到本地部署的 Qwen 或 Llama 模型，性能稍微下降但可控。

**Q4：你们的工具有没有通过 PDPO（香港个人资料私隐条例）合规审查？**
A：现阶段是学生研究项目，正式合规审查需要资金支持。但我们的**设计原则是 PDPO-by-design**：最小必要数据、用户可删除、人工审查后才输出。如果贵中心愿意做 pilot，我们可以一起跑一次 PDPO 自评估。

---

### B. 准确性与责任

**Q5：AI 抽错了字怎么办？比如把"陳"写成"陈"？**
A：**永远不会自动出文件**。每一个抽取结果都会进入审查界面，社工逐字逐栏勾选确认，系统才允许导出。AI 还会标注**置信度**——信心低的字段会高亮，提醒社工重点检查。简体/繁体我们做了规则强制（输入简体也会自动转繁体粤式中文）。

**Q6：如果填错表导致长者申请被拒，谁负责？**
A：**最终责任永远在签字的社工身上**——这一点我们在用户协议里写得很清楚。AI 是"草拟员"角色，不是"决策者"。这跟同工现在用 Word template 填表的法律边界是一样的——template 没有责任，填表人有责任。

**Q7：你们的 OCR 对粤式手写体准吗？特别是老社工的字？**
A：我们用的是 **GPT-5-mini Vision**，对中文手写训练充分，**粤式中文（如"咗、嘅、嚟"）识别率约 95%**。对极潦草的字会标注"不确定"让人审查。我们也欢迎贵中心提供 5-10 张实际样本让我们做 benchmark，下次面谈直接给您准确率数字。

---

### C. 学习曲线与培训

**Q8：我们的同工不太会用电脑，能上手吗？**
A：界面设计的目标是"**会用 WhatsApp 就会用 CareFlow**"——拖拽上传、点点点确认、按钮导出。我们最近测试，一个完全没用过 AI 的中年社工 **10 分钟可以独立跑完一遍**完整流程。如果贵中心希望，我们可以**上门做一次半小时培训**，免费。

**Q9：要不要装软件？我们 IT 部门很麻烦。**
A：不用装。**打开浏览器输入网址就能用**，跟用 Google Doc 一样。如果贵中心 IT 政策不允许 cloud，我们可以打包成 USB 一键启动版本，**不用经过 IT 部门审批**。

**Q10：如果同工录入到一半电脑坏了，资料会不会丢？**
A：每一步都**自动保存到本地数据库**。换台电脑登入同一个账号，案卷会自动同步回来。即使断网，已经下载到本地的资料也能继续审查。

---

### D. 商业模式与可持续性

**Q11：你们是学生项目，毕业了项目会不会就停了？**
A：这是非常合理的担心。我们的应对：
1. **代码全部开源（MIT 协议）**，托管在 GitHub，任何人都可以接手维护
2. 数据格式用**通用 PDF / Excel / Word**，没有锁定
3. 我们正在和腾讯公益、香港社联谈**长期托管方案**
4. 即使项目停了，贵中心已经导出的资料 100% 可携带，不会成为孤儿数据

**Q12：免费试行三个月之后呢？要收多少钱？**
A：商业模式上**我们尽可能维持非营利**。如果未来需要收费，定价模式会是"**按机构月费 + 实际 AI 用量成本**"，我们估算中型 NGO 一年总花费在 **HK$5,000 以内**——比聘一个 PT 实习生三个礼拜还便宜。详细成本估算我有一份 [docs/COSTS.md](../CareFlow/docs/COSTS.md) 可以发给您。

**Q13：腾讯给的 funding 用完之后呢？**
A：腾讯的资金主要 cover 我们做 demo + 第一批 NGO 试行。后续我们计划申请**社创基金 / 赛马会创新计划**，目标做 3-5 年的持续支持。如果贵中心愿意做案例研究合作伙伴，对我们申请基金有很大帮助。

---

### E. 与现有系统集成

**Q14：我们已经在用 ImpaCT 系统/某 NGO 中央系统，你们怎么衔接？**
A：CareFlow 的输出是**标准 Excel / Word / PDF**，可以直接喂给 ImpaCT 或任何中央系统。我们不替代既有系统，**只在前段帮同工把纸本/语音变结构化数据**。如果贵中心的系统有 API，我们后期也可以做直接对接。

**Q15：我们用的报告模板很特殊，每个项目都不一样，你们能处理吗？**
A：完全可以。这就是 **02 输出模板**模块的功能——上传贵中心的 .xlsx 或 .docx 模板，AI 会自动把抽取出的字段对应到您指定的栏位。**一次上传，永久重用**。今天 demo 时我可以现场用您的一份模板演示。

---

### F. 试行细节

**Q16：试行需要我们投入多少时间？**
A：最低限度：
- 第 0 周：30 分钟 onboarding + 上传 3 张贵中心常用表单
- 第 1-12 周：每周 0 时间投入，正常工作流程
- 每月一次：30 分钟反馈会议（可以 Zoom）
- 结束时：1 小时总结访谈

总投入 < 5 小时，**回报是节省的几十甚至上百小时文书时间**。

**Q17：我们能不能只先试一两个功能？**
A：当然。建议第一步只开 **α 志工纸本 → Excel**（最容易立刻见效），跑两周后再加 γ 福利表，再加 β 家访。**循序渐进，每一步都让同工自己感受到价值**。

**Q18：如果试行效果不好怎么办？**
A：**完全无条件退出**。我们会帮贵中心把所有数据导出，删除我们这边的任何痕迹（虽然本来也不存），并且我们也想听**为什么不好**——这是我们改进的关键。

---

### G. 神态/价值观（同工感性反应）

**Q19：你们这些年轻人，懂不懂前线的辛苦？**
A：（柔声）懂一些，但远远不够。所以我们今天是来听的，不是来教您怎么做。我自己做过 HKU Generation Connection 的家访义工，到过湾仔、沙田、马鞍山的长者中心。那种**爬六楼唐楼、长者开门那一刻的眼神**，我记得。我们做这个工具，是想让同工把那种眼神接得更久一些，**少看一些 Excel，多看一些人脸**。

**Q20：AI 会不会让社工变懒，失去专业判断？**
A：这正是我们设计上最警惕的事。所以**所有 AI 输出都强制人工审查**——同工不能"一键全部确认"，必须逐栏点开。我们希望 AI 像"**文书实习生**"——草拟、整理、提醒，但**专业判断永远是同工的**。
