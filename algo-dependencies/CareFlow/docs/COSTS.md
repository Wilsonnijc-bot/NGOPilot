# CareFlow · 營運成本評估（v0.4.5）

> 給 NGO 採購 / 預算審查參考。所有金額以美元（USD）為單位，並換算港幣（HKD）與人民幣（CNY），匯率取 1 USD ≈ 7.78 HKD ≈ 7.10 CNY。
> 假設使用模型清單（截至 2026-05-18）：
> - **DeepSeek-V4 Flash / Pro**（文字主力，估價依用戶提供）
> - **Azure OpenAI GPT-5-mini**（Vision 主力）
> - **GPT-4.1-mini**（Vision 備援）
> - **DashScope Fun-ASR**（粵語語音轉文字）

## 五、敏感性分析（What-if）

- **若全面切到 DeepSeek Pro（cache miss）**：β 每案上升至 ~$0.058、γ 每案 ~$0.009 — 月成本約 +20%，仍在 < HK$60 範圍。
- **若 ASR 用 Azure Whisper（$0.006/min ≈ $0.36/hour）**：β 每案上升至 ~$0.18 — 月成本 +HK$30 左右。
- **若全部關閉 Vision（降級為純文字輸入）**：α / γ / θ 退化至 DeepSeek-only，月成本可降至 ~HK$15。
- **若使用 4.1-mini 而非 5-mini 做 Vision**：影像輸入價格 +60%、輸出 -20%，整體影響 < 5%。

## 六、隱含成本（不含 AI API）

| 項目 | 月成本（HKD）|
|---|---:|
| 雲端伺服器（小型 4-core / 8GB · 例如 DigitalOcean）| ~HK$300 |
| 物件儲存（音訊 + PDF · S3 兼容）| ~HK$50 |
| 域名 + SSL | ~HK$30 |
| **基礎設施月成本** | **~HK$380** |

> 即使加上基礎設施，**整體月成本 < HK$430**，年度約 HK$5,000。

---

## 七、給 NGO 的對話要點

1. **試行階段成本可忽略不計**：用 demo + 一個 NGO 一個月，總 API 開銷預期 < HK$50。
2. **規模化後仍極經濟**：年度全機構部署，AI 成本不到聘任一位 PT 助理一年的 1/30。
3. **採購建議**：
   - 先用 DeepSeek Flash + GPT-5-mini 跑 6 週試行
   - 若 β 用量大，考慮自建 Whisper 或本地 Fun-ASR
   - DeepSeek Pro 僅在「關鍵欄位需高準確度」時切（例如金額、HKID 校驗）
4. **隱私不額外加錢**：transcript Fernet 加密、本地保存錄音是設計內預設，無需付費 add-on。
